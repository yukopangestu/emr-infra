Traffic contract

Only ALB-facing gateways are publicly reachable. East-west service calls use private DNS and security-group references; database ingress accepts TCP 5432 only from RDS Proxy.

MANAGEMENT SUBNET

Operations access

SSM Session Manager only; no public SSH. Corporate VPN → SSO + MFA → IAM role → private target.

Legacy bastion is disabled by default.
PRIVATE APP SUBNET

Fargate services & workers

Gateway, clinical services and asynchronous workers spread across {{ selected.azs }} AZs.

Outbound through NAT; no public IPs.
PRIVATE DATA SUBNET

RDS, Redis & proxy

Data services have no direct internet route. Security groups define narrowly scoped ingress.

Encryption at rest with customer-managed KMS.

Credential rule

Never store database passwords in Git, images, source code, or plain environment configuration. ECS task roles read only their scoped secret, bucket, and queue permissions.
